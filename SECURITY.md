# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| 1.0.x | Yes |
| < 1.0 | No |

## Reporting a Vulnerability

If you discover a potential security vulnerability in **Gaurav AI**, please report it responsibly by emailing **gauravkumar.yadav.dev@gmail.com** or creating a private security advisory on GitHub.

Do not disclose security vulnerabilities in public issue trackers.

We will investigate and acknowledge security reports within 48 hours.
