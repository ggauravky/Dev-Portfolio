# Contributing to Gaurav AI

Thank you for your interest in contributing to **Gaurav AI**!

---

## 🛠️ Development Workflow

1. **Fork & Clone**: Fork the repository and clone it locally.
2. **Branching**: Create a topic branch (`git checkout -b feature/my-feature`).
3. **Environment Setup**: Copy `.env.example` to `.env` and configure your API key.
4. **Testing**: Run `node --test backend/tests/*.test.js` to ensure all tests pass.
5. **Building**: Verify Vite production compilation with `npm run build`.
6. **Submitting PR**: Open a Pull Request against the `main` branch.

---

## 📝 Commit Guidelines

Follow conventional commit messages:
- `feat:` New feature
- `fix:` Bug fix
- `docs:` Documentation change
- `test:` Adding or updating tests
- `refactor:` Code refactoring
